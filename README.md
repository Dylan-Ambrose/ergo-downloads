# Ergo — Downloads

This repo hosts downloadable builds of [Ergo](https://github.com/Dylan-Ambrose/listic),
a minimal chat-bubble style to-do list app with per-task timers.

**No source code lives here** — this repo exists solely to distribute release binaries.
The source is developed privately.

## Get the app

See the [Releases](../../releases) page for the latest `Ergo.exe` — a portable,
single-file build for Windows. No installer needed; just run it.
